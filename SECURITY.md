# Security policy

## Status

noso-node-go is experimental and has had no independent security audit. Do not
use it to hold anything of value. Known findings and their status are in
[SECURITY_REVIEW.md](SECURITY_REVIEW.md).

## Supported versions

There are no tagged releases. Only the `main` branch is supported.

## Reporting a vulnerability

Use GitHub private vulnerability reporting: open the repository's **Security**
tab and choose **Report a vulnerability**. Do not open a public issue for a
vulnerability.

Include the affected commit, a description, and a reproduction using local data
and loopback peers only. Do not test against any network you do not own.

There is no response-time guarantee and no bounty program.
